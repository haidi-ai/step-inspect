# 部署说明 · ZNGL 几何体检落地页（T-0741）

> 本目录 = 纯静态站点：`index.html` + `sample-report.html` + `img/` 三张截图。
> **零依赖**：无 CDN、无外部字体、无统计脚本、无表单服务；页面不收集任何数据（表单只在本机生成 `mailto:` 草稿）。
> **不含**：ZNGL dist、ZNK 二进制、SDK、任何 `.js/.wasm/.dll/.exe` 文件、许可逻辑或"防破解"内容。
> 更新于 2026-11-23；部署前请重跑 `verify-landing.mjs`（见文末）。

## 1. 方案 A：GitHub Pages（零备案，境外）

**步骤**
1. 建**公开**仓库（如 `zngl-inspect-landing`），只提交上表"是"的文件。
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存。
3. 等 1–2 分钟，访问 `https://<用户名>.github.io/zngl-inspect-landing/`；`sample-report.html` 同路径拼接。
4. 自定义域名（可选）：加 `CNAME` 文件 + DNS CNAME 记录，开启 Enforce HTTPS。

**注意**
- **免费、自动 HTTPS、零备案**；但境内访问速度与稳定性不可控，且**页面内容与 GitHub 使用条款要自查**：GitHub Pages 条款不允许把它当成"以促成商业交易为主"的电商/收款站。纯展示 + 邮件联系的落地页处于灰区，**正式商用前请法务确认条款适用性**，或改用方案 C。
- 仓库公开 = 页面源码公开（本页无秘密，可接受）；**绝不要**为了图省事把 dist/二进制传上来。
- 无服务端，无法自定义安全响应头（CSP 等）；本页无外部资源，风险面小。

## 2. 方案 B：Gitee Pages（零备案，境内）

**步骤**
1. Gitee 建公开仓库并推送同批文件；完成**实名认证**。
2. 仓库 → 服务 → Gitee Pages → 选分支/目录 → 部署（部分账号需人工审核）。
3. 访问 `https://<用户名>.gitee.io/<仓库名>/`；自定义域名按页面提示配置。

**注意**
- 境内访问通常比 GitHub 快，但**免费版可用性、配额、是否需付费/企业版、自定义域名是否要求备案，均以 Gitee 当前官方公告为准**（本文件写于 2026-11-23，未实测开通，**未验证**）。
- 审核可能拒绝"营销/商业"类页面，**部署前先看最新条款**；被拒就退回方案 A 或 C。
- 同样只传静态文件；不要放任何安装包。

## 3. 方案 C：阿里云 OSS 香港（零备案，按量计费）

**步骤（控制台）**
1. 开通 OSS，创建 Bucket：地域**中国香港**、读写权限**公共读**、**关闭**"阻止公共访问"（否则静态网站打不开）。
2. Bucket → 数据管理 → 静态页面：默认首页 `index.html`、默认 404 `index.html`（单页站）。
3. 上传 `index.html`、`sample-report.html`、`img/`（保持相对路径）。
4. 访问：`http://<bucket>.oss-cn-hongkong.aliyuncs.com/index.html`。
5. 正式对外**建议绑定自定义域名 + HTTPS 证书**（OSS 支持托管证书）；DNS 加 CNAME 到 Bucket 外网域名。

**注意**
- 香港节点**不需要工信部 ICP 备案**（境外/港澳），这是"零备案"的关键；但**面向境内用户提供经营性服务可能涉及其他资质，待法务确认**。
- 阿里云 OSS **默认域名访问网页文件可能被强制下载或限制预览**（平台策略会变），所以正式上线请绑自定义域名；以阿里云当前文档为准。
- **费用**：存储极小（本包 < 1 MB），主要成本是外网流出流量与请求数，按量计费；上线前设**流量封顶/告警**，防被刷。
- **访问日志默认关闭就别开**：开启会产生访问者 IP 等日志，属于个人信息处理，需在隐私政策中披露并做法务评估。
- 无法像 Nginx 那样自由加安全头；如需 CSP/HSTS，建议前面挂 CDN 或改用轻量云主机（但那就要备案/运维，超出"零备案"范围）。

## 4. 数据合规与表单（重要，别省）

- **表单只 mailto**：字段在本机拼成 `mailto:` 草稿，**不向服务器提交**；页面无第三方脚本、无 cookie、无统计。部署后可用浏览器 DevTools → Network 复核：除本站文件外**零请求**。
- **境外托管的数据合规待法务**：即使用户只是"访问页面"，OSS/GitHub 侧仍会产生访问日志（IP、UA），是否构成个人信息出境/处理，需法务按《个人信息保护法》等评估；**本页当前不主动收集任何数据**，这是把风险压到最低的前提。
- 若将来要接表单服务（Formspree/金数据等）：先补隐私政策、告知同意、跨境与留存期限，再上线；**当前不接**。
- 页面上的邮箱是公开业务邮箱；收到图纸即属于客户数据，按"项目结束 30 天删除（待法务确认）"执行，不外发、不外包。
- **禁止**：不要在本目录/仓库里放客户图纸、真实客户名、许可证文件、密钥。
